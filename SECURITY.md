# Security Policy

## Supported Versions

| Version       | Supported          |
| ------------- | ------------------ |
| latest `main` | :white_check_mark: |
| older commits | :x:                |

## Reporting a Vulnerability

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/ilyalavrenov/birdfeeder/security/advisories/new).
Please do not open a public issue.

Include the steps to reproduce and what you observed. Expect an initial response
within a few days.
